{% comment %} Diálogo para cancelar un pago pendiente. Lo usan la lista de transferencias pendientes y el formulario de transferencia. Expone una función global: abrirCancelDialog(paymentId, onSuccess, opciones). - onSuccess: se llama después de que el servidor confirmó la cancelación. - opciones.titulo y opciones.mensaje: para el caso "vas a perder este pago", cuando el operador cambia de pantalla y hay un pendiente abierto. El motivo siempre lo elige una persona: es plata, y "Otro" exige el detalle escrito. El backend lo valida igual; esto solo lo avisa antes. {% endcomment %}
